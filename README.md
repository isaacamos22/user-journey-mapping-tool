# User Journey Mapping Tool

Local workbench for UX and product owners: workshop in **Figma / FigJam**, import via **Cursor chat**, map, Discovery, export.

**Public repo** = application source only. **Workshop journeys, discovery drafts, and the database live on your laptop** (see `.gitignore`).

## Install + run (5 min)

**[`journey-app/docs/GETTING_STARTED.md`](journey-app/docs/GETTING_STARTED.md)** — one copy-paste prompt for Cursor Agent (clone, npm, dev).

## Share a journey with someone else

1. In the app: **Export** → `pack.zip`.
2. They import in **their** local app via Cursor (their own `dev.db`).

Do **not** commit workshop content to this repo.
